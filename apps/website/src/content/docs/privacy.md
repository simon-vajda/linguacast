_Last updated: 26 September 2026._

## 1. Scope of this policy

Hallspeak is open-source, self-hosted software: anyone can run a Hallspeak server for their own events. This policy is from Simon Vajda ("we", "us"), who publishes the Hallspeak app for iOS and Android and runs this website (hallspeak.app).

This policy does not cover Hallspeak servers run by others. Each event takes place on a server operated by the organisation hosting it, such as a church, school or conference organiser, and that organisation is responsible for how its server handles your information. Questions about an event should go to them.

## 2. Information we collect

**None.** The app contains no analytics, advertising, crash-reporting or tracking code, and has no accounts. It never sends anything to us.

## 3. What the app sends to an event's server

To deliver live audio, the app talks only to the server of the event you join, and sends it:

- your device's IP address and network connection details, which any internet connection reveals and which are needed to stream audio to you
- the event PIN you enter or scan
- the app's version number, so the server can check it is compatible
- if you use **Report a problem**, the category you picked (for example, no sound), with no name, message or other identifying detail

The server may keep this in its logs for as long as its operator chooses.

## 4. Locally stored data

The mobile app keeps the events you have joined or pinned, and your appearance settings, on your device only. Deleting the app removes them.

## 5. Device permissions

**Camera**: used only to scan an event's QR code. Images are processed on the device and are neither saved nor sent anywhere.

## 6. This website

This website is hosted on GitHub Pages. GitHub may log your IP address when you visit, as described in the [GitHub privacy statement](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement). The site stores your light or dark theme choice in your browser and uses no analytics or tracking cookies.
